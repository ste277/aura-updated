# AURA-DISK-02 — 05 Recovery and Rollback

## 1. What survives a retirement
- The local branch `B` and its HEAD `H` (recorded per row in DISK02_02). `git worktree remove` never deletes branches.
- Every commit. Each HEAD is an ancestor of `origin/main` (`1741a95`), so the content is also on GitHub.
- Repository-wide refs: `refs/stash`, `refs/codex/*`, tags, remote-tracking refs.

What is lost (all regenerable or duplicated elsewhere):
- Build output (`apps/web/.next`, `.next-dev`, `tsconfig.tsbuildinfo`).
- Real `node_modules` copies (insights-v1-pr6, location-pr8) — reinstallable from `package-lock.json`.
- The two `node_modules` symlinks and any `.env.local` symlink or copy, all of which point to or match the main checkout.
- The worktree's own HEAD reflog. The preflight found **0** commits reachable only from these reflogs.

## 2. Recreating a retired worktree

From the main checkout root, with `N`, `B` and `H` from the CSV:

```
git worktree add .claude/worktrees/N B
git -C .claude/worktrees/N rev-parse HEAD   # must equal H
```

If branch `B` was deleted later for any reason: `git worktree add --detach .claude/worktrees/N H`. `H` is reachable from `origin/main`, so the commit cannot be lost.

Then restore the environment that worktree had:

| Worktree type | Restore step |
|---|---|
| M1 (38, symlinked deps) | `ln -s /Users/stephen/Desktop/Claude/auraschedule-math-core/node_modules .claude/worktrees/N/node_modules` and `ln -s /Users/stephen/Desktop/Claude/auraschedule-math-core/apps/web/node_modules .claude/worktrees/N/apps/web/node_modules` |
| M2 (insights-v1-pr6, location-pr8) | `npm ci` in the worktree (own dependencies) |
| `.env.local` symlink (insights-v1-pr4, -pr5, -pr6) | `ln -s /Users/stephen/Desktop/Claude/auraschedule-math-core/apps/web/.env.local .claude/worktrees/N/apps/web/.env.local` |
| `.env.local` copy (location-pr8) | copy main's `apps/web/.env.local` (byte-identical at preflight, SHA-256 prefix 90d4416fa91e) |
| Build output | regenerated by the next `next build` / `next dev` |

Prerequisites for recovery:
1. The main checkout and its `.git` must still exist.
2. Branches must not have been deleted, or the `origin/main` objects must be present (they are, locally).
3. About 15–20 MiB of free space per source checkout, plus dependency and build space if rebuilt fully.

## 3. Mid-run rollback (M1 interrupted)

If the two symlinks were unlinked but `git worktree remove` refused or was not run, recreate the links with the two `ln -s` commands above. The worktree is then exactly as it was at preflight. Record the event and re-audit before any retry.

## 4. Irreversibility statement

Once removed, a worktree's directory contents are gone. The only things that cannot be rebuilt by §2 are the per-worktree HEAD reflog and any change made after this preflight. The per-worktree gate (04 §3) exists to catch such changes, and the reflog was shown to hold no unique commits.
