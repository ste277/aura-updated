## Rules for this tracker

1. **Record only what reviewers actually returned.** Never pre-fill, infer or summarise a decision on a reviewer's behalf. Quote comments verbatim; if a quote is shortened, mark it `[…]` and keep the full text in the reconciliation file.
2. A review counts only if it references SHA-256 `d5fb7a1e30c6…` or "G3 v1.1 (draft)". A review of any other version is logged but not counted.
3. **Status values for each item:** `NOT ASSIGNED` → `AWAITING` → `RETURNED` → one of `AGREED` / `CORRECTION REQUESTED` / `CONFLICT` / `ACCEPTED AS OPEN` → (for corrections) `CORRECTION PROPOSED` → `CHANGE AUTHORIZED` → `REVISED` → `RECONFIRMED`.
4. **Conflicts are never auto-resolved.** If reviewers disagree, mark `CONFLICT` and escalate to the product owner. A reviewer's recommendation is not a product decision until the product owner records it.
5. An unresolved question stays `OPEN` until a reviewer answers it, or explicitly accepts it as open. An approved change is listed only in §7, with its authorization.
6. Nothing here changes application content, citations, drawings, disclosures or the approval record. Those changes need separate authorization (see §7).
